# Пикабу Игры

Публикуем **напрямую через Пикабу** (как «Ночной тариф», «Мутация» и «Выжить до пятницы»).
Игра для Пикабу лежит на нашем сайте: **https://forestpost.games/pikabu/** — страница `pikabu/index.html`, её собирает `tools/build_pikabu.py`
(вызывается из `tools/site.py`; после правок `pochta/index.html` — пересобрать). Графика и звук — из `pochta/` через `<base href="/pochta/">`;
поисковикам — `noindex` и `Disallow: /pikabu/` в robots.txt.

## Что делает сборка (`window.LP_PLATFORM = 'pikabu'`)
- SDK Пикабу (`https://games.pikabu.ru/sdk/sdk.js`, `PkbSDK`), `gameStarted()` после загрузки; реклама при загрузке не показывается.
- Облачное сохранение `storage` ключ `lp`; при входе прогресс объединяется (звёзды — по максимуму, постройки — объединение).
- Реклама: за награду (+5 ходов до 2 раз в день, молоток раз за письмо, ×2 монеты; нет ролика — награда без него), межстраничная — не в первых 5 письмах, не чаще раза в 2,5 минуты, только между письмами; пауза и тишина на время рекламы.
- Покупки: окно оплаты Пикабу (гостя просят войти) → `purchase.getSignedData()` → функция Supabase `lp-pikabu` проверяет подпись ключом `LP_PIKABU_SECRET`, пишет в `lp_pk_purchases` → покупка зачисляется; расходуемые подтверждаются `consumePurchase`; не подтверждённые не зачисляются и возвращаются при следующем запуске (`getPurchases`).
- Турнир недели: таблица игроков Пикабу (`pk-<id>`), игрок проверяется подписью `player.getSignedData()` в функции `lp-tour`.
- Выключено: строка документов с данными владельца, ссылки на сайт и соцсети (открытка — картинкой), демо-режим.

## Файлы для Студии — `promo/pikabu/`
- `teksty-pikabu.docx` / `.txt` — все поля Студии, товары, SEO и порядок действий (собирает `tools/pikabu_docs.py`).
- `tovary-pikabu.csv` — 7 товаров (id менять нельзя).
- `icon-1024x1024.png`, `cover-1920x1080.jpg`, `screen-1…5-1280x720.jpg` и архив `lesnaya-pochta-pikabu-izobrazheniya.zip` (рисует `tools/promo_pikabu.js` из кадров игры; запуск: `NODE_PATH=$(npm root -g) node tools/promo_pikabu.js`).

## Что сделать владельцу
1. Студия → Добавить игру: ссылка `https://forestpost.games/pikabu/`, тексты и картинки из `promo/pikabu/`.
2. Товары из `tovary-pikabu.csv`.
3. Секретный ключ игры → секрет функций Supabase `LP_PIKABU_SECRET` (через форму, не в чат).
4. Тестовое окружение → прислать ссылку Claude → проверка с настоящим SDK.
5. Отправить на модерацию.
